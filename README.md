## Overview

The Women Safety Device is an IoT-based emergency response system developed to enhance personal safety. The device can send alerts and location information during emergency situations, enabling quick assistance.

## Features

- SOS Emergency Alert System
- Real-Time GPS Tracking
- Location Sharing
- GSM-Based Communication
- Portable Hardware Prototype
- Real-Time Monitoring

## Hardware Components

- ESP32
- GPS Module
- GSM Module
- Push Button
- Breadboard Prototype
- Power Supply Unit

## Working

When the emergency button is activated, the device retrieves the current GPS coordinates and transmits the location information through the communication module. This enables rapid response and location tracking during emergency situations.

## Applications

- Women Safety
- Student Safety
- Personal Security
- Emergency Response Systems
- Location Tracking Solutions
